## Escape the Maze

Escape the Maze is a game developed in Unity where the goal is to find the character's home before the time runs out.

## Features
- Maze exploration.
- Simple controls.
- Browser-playable version.

## Technologies used
- Unity
- C#
- WebGL

## How to play
Use the arrow keys to move.
Find the house in the maze.
Play online
